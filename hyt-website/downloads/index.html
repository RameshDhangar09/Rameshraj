Using our documents

From catalogue to proposal

Catalogues give an overview of each machine, its main options and its typical applications. Every HYT machine is configured for the customer's gauge, wheel profiles and vehicles, so final technical data is always confirmed in the technical offer.

Each product page also carries its own catalogue button, so you can download the document for a single machine while reading about it. Start from the product overview to find the machine you need.

Need a drawing, a datasheet or tender documentation that is not listed here? Contact us and tell us which machine and which project it is for.
