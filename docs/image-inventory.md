# Image inventory (sample imagery)

All photographs-style images on the HYT website are currently **generated sample illustrations**, not photographs. Each one carries a small "SAMPLE IMAGE" label in the bottom-right corner so it cannot be mistaken for a real photograph of HYT equipment, projects, people or premises.

**Status: SAMPLE – replace with approved HYT photograph**, except the product photographs marked **HYT PHOTO** (received 19 Oct 2026, plus new files `products/surface-wheel-lathe-ysl-12.jpg` and `products/surface-wheel-lathe-ysl-21.jpg`).

## Replacement specification

- Keep the **same filename and folder** so no HTML changes are needed.
- Aspect ratio **16:10** (main file at least **1600×1000**, responsive copy `-800.jpg` at 800×500).
- Exception: the homepage hero is **2:1** — `hero-wheel-lathe-workshop.jpg` at least **2400×1200** plus `-1200.jpg` at 1200×600. Keep the left ~45% of the hero visually calm/darker, because the white headline sits over it.
- Format **JPG**, sRGB, quality ~80–85; aim for ≤350 KB at 1600 px (≤600 KB for the 2400 px hero).
- Use only photographs HYT owns or has written permission to publish; check identifiable people have consented; remove the "SAMPLE IMAGE" label requirement once real photos are in place.

## How to regenerate the samples

The samples are drawn by a small 3D-to-SVG renderer and rasterised with headless Chromium. Sources: `tools/image-generator/` (`lib/` = engine, primitives and reusable components such as wheelsets, rails, pits, halls, bogies, coaches, metro cars, locomotive and machines; `scenes/` = one function per image).

```sh
cd tools/image-generator
npm i playwright-core@1.56.1        # once; node_modules is git-ignored (or set PLAYWRIGHT_CORE=/path/to/playwright-core)
CHROMIUM=/path/to/chrome ./run.sh   # all images (default Chromium path: /opt/pw-browsers/chromium-1194/chrome-linux/chrome)
./run.sh --only hero-wheel-lathe-workshop,wheel-press   # selected images
./run.sh --out /tmp/preview         # render elsewhere for review
```

The renderer writes both sizes for each scene into `hyt-website/assets/images/<folder>/`, adds the "SAMPLE IMAGE" label, and lowers JPG quality from 82 only if a file exceeds its size budget. Do not run `playwright install`; point `CHROMIUM` at an existing Chromium/Chrome binary.
